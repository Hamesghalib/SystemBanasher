# تطبيق بنشر النخبة — مشروع Android

هذا مشروع Apache Cordova يحوّل صفحة النظام المحاسبي العربية إلى تطبيق Android. الواجهة وبياناتها المحلية ضمن `www/`، وأيقونة التطبيق في `www/res/icon.png`. تستخدم الصفحة `localStorage` للاحتفاظ بالبيانات محلياً على الجهاز؛ خذ نسخة احتياطية من داخل التطبيق بانتظام.

## متطلبات البناء

- Linux أو Windows/macOS بمعمارية x86-64، مع Android SDK (Android platform 33 وBuild Tools 33.0.2).
- JDK 17، وNode.js وnpm.
- Cordova 12 وcordova-android 12 (تثبّت عبر خطوات المشروع أدناه).

> ملاحظة: بناء APK غير مكتمل داخل بيئة إنشاء هذه الحزمة، لأن حاسوب البناء المتاح يعمل بمعمارية ARM64 بينما أدوات Android الرسمية المطلوبة هنا (`aapt2`) مبنية لـx86-64. الشيفرة والمشروع جاهزان للبناء في بيئة التطوير المتوافقة.

## بناء APK تجريبي

من مجلد المشروع:

```bash
npm install
npx cordova platform add android@12.0.0
npx cordova build android --debug
```

الناتج المتوقع:

```text
platforms/android/app/build/outputs/apk/debug/app-debug.apk
```

لإنشاء إصدار نشر، جهّز مفتاح توقيع خاصاً بك واستخدم إعدادات التوقيع الرسمية في Cordova/Gradle؛ لا تشارك ملف المفتاح أو كلمات مروره.

## ملاحظات تشغيل

- النسخة الحالية تعمل محلياً ولا تحتاج إلى خادم أو اتصال دائم بالإنترنت لوظائف الصفحة الموجودة.
- التخزين محلي على الجهاز؛ حذف التطبيق أو بياناته قد يمحو سجلاته، لذا احتفظ بالنسخ الاحتياطية.
- الحزمة الناتجة من `--debug` مخصصة للاختبار، وليست إصداراً موقّعاً للنشر في المتجر.
